# Security Policy

## Supported Versions

The following versions of **Saknussemm** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project and its dependencies seriously. If you discover a potential security vulnerability, please do NOT create a public issue on GitHub.

Instead, please report security issues through GitHub's Private Vulnerability Reporting feature:
1. Navigate to the repository's **Security** tab.
2. Under "Security", click **Report a vulnerability**.
3. Provide details and reproduction steps.

Alternatively, you can open a private discussion with the maintainer (@devpryan7792).

### What to include in your report:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Potential impact and mitigation recommendations.

Thank you for helping keep Saknussemm safe for all travelers!
